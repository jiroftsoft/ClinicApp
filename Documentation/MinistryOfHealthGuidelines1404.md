## 📐 فرمول محاسبه قیمت نهایی

### فرمول پایه:
```
قیمت نهایی = (جزء فنی × کای فنی) + (جزء حرفه‌ای × کای حرفه‌ای)
```

### مثال محاسبه: کد 970000 (ویزیت پزشک عمومی)

#### مشخصات خدمت:
- **کد:** 970000
- **ویژگی:** هشتگ‌دار (#)
- **جزء فنی:** 0.5
- **جزء حرفه‌ای:** 1.3

#### انتخاب K-Factors:
- **کای فنی:** 
  - کد 970000 در کد (۷) کتاب ارزش نسبی قرار دارد
  - استفاده از K-Factor کد 7: **2,750,000 ریال**
- **کای حرفه‌ای:** 
  - خدمت هشتگ‌دار است
  - استفاده از K-Factor هشتگ‌دار: **770,000 ریال**

#### محاسبه:
```
جزء فنی: 0.5 × 2,750,000 = 1,375,000 ریال
جزء حرفه‌ای: 1.3 × 770,000 = 1,001,000 ریال
─────────────────────────────────────────
قیمت کل: 2,376,000 ریال ✅
```

2. **`FactorSettingSeedService.cs`**
   - Seed کردن K-Factors سال 1404
   - استفاده از `SeedConstants.FactorSettings1404`

3. **`SeedConstants.cs`**
   - مقادیر ثابت K-Factors:
     - `TechnicalHash_1_7 = 2,750,000`
     - `TechnicalHash_8_9 = 2,600,000`
     - `ProfessionalHash = 770,000`

### منطق انتخاب K-Factor فنی:

```csharp
if (service.ServiceCode.StartsWith("97"))
{
    // کدهای 97xxxx (ویزیت‌ها) از K-Factor کد 7 استفاده می‌کنند
    targetScope = FactorScope.Hash_1_7; // 2,750,000 ریال
}
else if (firstDigit >= 1 && firstDigit <= 7)
{
    // کدهای 100xxx تا 700xxx
    targetScope = FactorScope.Hash_1_7; // 2,750,000 ریال
}
else if (firstDigit == 8 || (firstDigit == 9 && !service.ServiceCode.StartsWith("97")))
{
    // کدهای 800xxx و 900xxx (غیر از 97xxxx)
    targetScope = FactorScope.Hash_8_9; // 2,600,000 ریال
}
```
