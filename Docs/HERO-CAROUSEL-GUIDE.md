# راهنمای کروسل هیرو — کلینیک شفا

## 🎯 اهداف کروسل در سایت کلینیک

| هدف | توضیح |
|-----|--------|
| ✅ معرفی سریع کلینیک | کاربر در چند ثانیه بفهمد کلینیک کیست و چه می‌کند. |
| ✅ هدایت به نوبت‌دهی | CTA واضح: «رزرو نوبت» به‌عنوان اقدام اصلی. |
| ✅ ایجاد حس اعتماد | تصویر واقعی پزشک/محیط، تخصص، تجهیزات. |
| ✅ کم‌بار شناختی (Low Cognitive Load) | یک پیام در هر اسلاید؛ بدون شلوغی. |
| ❌ ضد الگو | کروسل شلوغ تبلیغاتی = ضد UX پزشکی. |

## 🧠 ساختار پیشنهادی (حداکثر ۳ اسلاید)

### اسلاید ۱ — پیام اصلی
- **عنوان:** کلینیک تخصصی درمانی شفا  
- **زیرعنوان:** تشخیص دقیق، درمان مطمئن  
- **CTA:** رزرو نوبت  

### اسلاید ۲ — تخصص
- **عنوان:** تیم پزشکان مجرب  
- **زیرعنوان:** همراه شما از تشخیص تا درمان  
- **CTA:** مشاهده پزشکان  

### اسلاید ۳ — اعتماد
- **عنوان:** تجهیزات مدرن و محیط ایمن  
- **زیرعنوان:** مطابق استانداردهای روز پزشکی  
- **CTA:** درباره کلینیک  

محتوای واقعی از CMS (اسلایدر) می‌آید؛ این ساختار فقط الگوی محتوایی است.

## ⚙️ مشخصات فنی (پیاده‌سازی فعلی)

| مورد | مقدار / رفتار |
|------|----------------|
| **Auto-play** | ❌ غیرفعال پیش‌فرض (کنترل دست کاربر) |
| **Swipe** | ✅ فعال در موبایل |
| **Transition** | 300–500ms (فعلاً 400ms) |
| **Lazy loading** | ✅ فقط اسلاید اول با تصویر اینلاین؛ بقیه با `data-image-url` و بارگذاری هنگام نمایش |
| **حداکثر اسلاید** | ۳ (در View با `Take(3)` اعمال می‌شود) |
| **کیبورد** | فلش‌ها، Home/End، Space (توقف/شروع اختیاری) |
| **دکمه Play/Pause** | نمایش داده می‌شود؛ کاربر در صورت تمایل می‌تواند پخش خودکار را روشن کند |
