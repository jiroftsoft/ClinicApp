## 🚀 **شروع سریع**

### **1. برای به‌روزرسانی یک ماژول:**

```bash
# به Cursor بدهید:
"لطفا این ماژول را طبق راهنمای JALALIDATEPICKER_MIGRATION_GUIDE.md به‌روزرسانی کن"
```

### **2. برای استفاده از Component:**

```html
<!-- ✅ اضافه کردن به View -->
<input type="text" 
       data-jdp
       data-jdp-theme="medical"
       data-jdp-size="medium"
       data-no-default-date="true" />
```

## 📝 **نکات مهم**

### ✅ **Component به صورت خودکار initialize می‌شود**

نیازی به initialization دستی نیست. فقط `data-jdp` را اضافه کنید.

### ✅ **برای Inputهای داینامیک**

از `JalaliDatePickerEnterprise.init()` استفاده کنید.

### ✅ **Events**

- `pDatepicker:select` (backward compatible)
- `jdp:change` (native event)
