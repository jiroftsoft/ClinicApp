# 📐 استانداردهای اندازه لوگو برای محیط درمانی

این سند شامل استانداردهای اندازه لوگو برای استفاده در بخش‌های مختلف سیستم است.

---

## 🎯 ۱) اندازه استاندارد لوگو برای وب‌سایت

### ✔ **هدر (Header / Navbar)**

- **ارتفاع: 50px** (استاندارد برای سایت‌های رسمی درمانی)
- **عرض: حداکثر 200px** (برای لوگوی افقی 3:1 یا 4:1)
- **موبایل: ارتفاع 40px، عرض حداکثر 160px**

### ✔ **فوتر (Footer)**

- **ارتفاع: 50px** (استاندارد برای سایت‌های رسمی درمانی)
- **عرض: حداکثر 200px** (برای لوگوی افقی 3:1 یا 4:1)
- **موبایل: ارتفاع 40px، عرض حداکثر 160px**

### ✔ **فایل آپلودی برای وب**

- **بهترین رزولوشن: 500×500 px**
- **فرمت ترجیحی: SVG**
- **اگر PNG: با بک‌گراند ترنسپرنت**

---

## 🎯 ۲) اندازه استاندارد لوگو برای موبایل / اپلیکیشن

### ✔ **Launcher Icon (آیکون برنامه)**

- **اندروید: 512×512 px**
- **iOS: 1024×1024 px**

(لوگو برای اپ باید داخل safe area باشد)

---

## 🎯 ۳) اندازه استاندارد لوگو برای شبکه‌های اجتماعی

- **پروفایل اینستاگرام: 320×320 px**
- **پروفایل تلگرام: 512×512 px**
- **پروفایل لینکدین: 400×400 px**
- **پروفایل X: 400×400 px**

**نکته:** نسخه اصلی ترجیحاً 1000×1000 px یا بیشتر باشد.

---

## 🎯 ۴) اندازه استاندارد لوگو برای چاپ

برای چاپ، دقت مهم‌تر از پیکسل است:

- **حداقل: 300 DPI** (ضروری برای چاپ)
- **کارت ویزیت:** لوگو معمولاً حدود 25 تا 40 میلی‌متر
- **سربرگ:** معمولاً 25 تا 35 mm ارتفاع
- **پوستر/بنر بزرگ:** فایل باید وکتور (SVG / PDF) باشد.

---

## 🎯 ۵) سایز اصلی Master Logo (فایل مادر)

برای یک لوگوی حرفه‌ای، همیشه این اندازه‌ها را می‌سازند:

- **2000×2000 px** (نسخه مربعی)
- **4000 px طولانی** (نسخه مستطیلی افقی)
- **نسخه SVG** (استاندارد طلایی)

این‌ها به شما اجازه می‌دهد برای هر محیطی خروجی بگیرید.

---

## 🎯 ۶) نسبت استاندارد لوگو

طراحان در برندینگ از نسبت‌های زیر استفاده می‌کنند:

- **مربعی: 1:1**
- **افقی: 3:1 یا 4:1** (برای محیط‌های درمانی توصیه می‌شود)
- **عمودی: 1:2**

برای محیط‌های درمانی معمولاً **لوگوی افقی 3:1** بیشتر توصیه می‌شود (رسمی‌تر و خواناتر).

---

## ✨ خلاصه استانداردها

| کاربرد       | اندازه‌ی پیشنهادی                  |
| ------------ | ---------------------------------- |
| هدر وب       | ارتفاع 50px                        |
| فوتر         | ارتفاع 50px (موبایل: 40px)        |
| آپلود لوگو   | 500×500 px                         |
| Master       | 2000×2000 px + فایل SVG            |
| اپلیکیشن     | 512×512 (Android)، 1024×1024 (iOS) |
| شبکه اجتماعی | 400×400 px                         |
| چاپ          | 300 DPI                            |
