# نقشه راه اتمیک — داشبورد بیمار

**هدف:** انجام موارد ضروری به صورت گام‌های کوچک و اتمیک، بدون شکست ماژول یا پروژه.

**اصول:**
- هر گام مستقل و قابل تست است.
- پس از هر گام، داشبورد و تب‌ها باید بدون خطا کار کنند.
- در صورت بروز مشکل، می‌توان تنها همان گام را برگرداند.
