# چک‌لیست پروداکشن — نقش‌محور و گاد مود

## انجام‌شده

- **پروفایل:** در منوی کاربر (داشبورد، پروفایل من، تنظیمات، خروج) نقش «منشی» یا «مدیر» نمایش داده می‌شود؛ لینک داشبورد برای منشی → داشبورد منشی.
- **داشبورد ادمین:** منشی با ورود به `/Admin/Dashboard` به داشبورد منشی ریدایرکت می‌شود.
- **داشبورد پزشکان:** منشی با ورود به `/Admin/DoctorDashboard` به داشبورد منشی ریدایرکت می‌شود.
- **Breadcrumb:** برای منشی لینک «داشبورد منشی» و مسیر صحیح.
- **منو:** منشی فقط داشبورد منشی، پذیرش، مالی مجاز و … را می‌بیند؛ بدون کاربران، CMS، تنظیمات سیستم.
- **عملیات سریع (سایدبار):** دکمه «کلینیک جدید» فقط برای غیرمنشی نمایش داده می‌شود.
- **کنترلرهای پذیرش:** `[Authorize(Roles = Admin + Receptionist)]` روی ReceptionV2، ReceptionApiV1، ReceptionListV2.

## گاد مود بک‌اند

| کنترلر | رفتار برای منشی |
|--------|------------------|
| Dashboard | ریدایرکت → ReceptionistDashboard |
| DoctorDashboard | ریدایرکت → ReceptionistDashboard |
| ReceptionistDashboard | دسترسی مجاز |
| ReceptionV2 / API / ReceptionList | دسترسی مجاز |
| UserManagement, SystemSeed, FactorSetting, CMS | منشی لینک نمی‌بیند؛ در صورت URL مستقیم → 403 |

## UI/UX پروداکشن

- نشان نقش (بج منشی/مدیر) در هدر پروفایل و در dropdown.
- لینک‌های منو و breadcrumb نقش‌محور.
- منشی گزینه «تنظیمات» در dropdown ندارد (تنظیمات سیستم مخصوص ادمین).

## پیشنهاد بعدی (اختیاری)

- اضافه کردن فیلتر `[ReceptionistOnly]` برای اکشن‌های حساس در صورت نیاز.
- لاگ دسترسی نامجاز (مثلاً درخواست منشی به Dashboard) برای ممیزی.
