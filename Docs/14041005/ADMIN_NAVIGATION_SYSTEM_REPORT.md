## 📚 **نحوه افزودن ماژول جدید:**

### **مثال: اضافه کردن "مدیریت داروها"**

1. در `_AdminModulesMenu.cshtml` اضافه کنید:

```csharp
new { 
    Name = "Medicine", 
    Title = "داروها", 
    Icon = "fa-pills", 
    Controller = "Medicine", 
    Category = "مدیریت کلینیک" 
}
```

2. اگر Controller در زیر‌پوشه است، Route اضافه کنید:

```csharp
// در AdminAreaRegistration.cs
context.MapRoute(
    name: "Admin_Medicine_Routes",
    url: "Admin/Medicine/{action}/{id}",
    defaults: new { controller = "Medicine", action = "Index", id = UrlParameter.Optional },
    namespaces: new[] { "ClinicApp.Areas.Admin.Controllers" }
);
```
