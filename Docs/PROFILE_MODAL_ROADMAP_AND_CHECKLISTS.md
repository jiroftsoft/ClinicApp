## لیست ۱: بررسی و انطباق با پروداکشن درمانی

چک‌لیست برای اطمینان از انطباق مودال پروفایل با محیط پروداکشن واقعی درمانی:

- [x] **رنگ‌بندی:** فقط استفاده از متغیرهای `--medical-primary`, `--medical-secondary`, `--medical-success`, `--medical-danger` (بدون گرادینت و رنگ‌های جیق)
- [x] **فونت:** Vazir / Vazirmatn برای متن فارسی و برچسب‌ها
- [x] **RTL:** جهت راست‌به‌چپ و چیدمان مناسب برای فارسی
- [x] **احراز هویت:** مودال فقط برای کاربر لاگین‌شده؛ endpoint با `[Authorize]` و در صورت نیاز `[NoCache]`
- [x] **امنیت فرم:** ارسال `__RequestVerificationToken` در POST پروفایل؛ عدم افشای کد ملی/موبایل در URL یا لاگ
- [x] **داده حساس:** کد ملی و موبایل فقط‌خوانا (readonly) و در صورت نیاز ماسک در نمایش/لاگ
- [x] **پیام‌ها:** استفاده از Toastr یا Notify برای موفقیت/خطا؛ بدون `alert()` یا `confirm()`
- [x] **دسترسی‌پذیری:** عنوان مودال با `aria-labelledby`، `aria-modal="true"`، تمرکز اول روی مودال هنگام باز شدن و برگشت به تریگر هنگام بستن
- [x] **بستن مودال:** دکمه بستن، کلیک روی Backdrop و کلید Escape
- [x] **ریسپانسیو:** قابل استفاده در موبایل و دسکتاپ (عرض و اسکرول داخلی مناسب)
- [x] **سازگاری با قرارداد:** Strongly-Typed ViewModel، استفاده از `UserProfileComponent` و همان API پروفایل صفحه کامل

## لیست ۲: بهینه‌سازی‌های انجام‌شده و پیشنهادی

اقدامات بهینه‌سازی برای مودال پروفایل در صفحه اصلی:

### انجام‌شده

1. **بارگذاری تنبل (Lazy):** محتوای مودال فقط با اولین باز شدن (یا با هر باز شدن) از طریق AJAX از `LoadProfileComponent` با پارامترهای مودال بارگذاری می‌شود.
2. **پیکربندی مودال برای کامپوننت:** فراخوانی `LoadProfileComponent` با `showHeader=false`, `cancelButtonText=بستن`, `containerClass=col-12` برای ظاهر مناسب داخل مودال.
3. **راه‌اندازی فرم پس از لود:** بعد از قرارگیری HTML در مودال، `UserProfileComponent.init()` برای همان container فراخوانی می‌شود تا ارسال AJAX و اعتبارسنجی کار کند.
4. **یک نقطه ورود واحد:** تابع سراسری `window.openProfileModal()` برای باز کردن مودال از منوی کاربر یا هر المان دارای `data-open-profile-modal="true"`.
5. **مدیریت تمرکز و Escape:** بستن مودال با Escape و بازگرداندن تمرکز به دکمه منوی پروفایل.
6. **استایل اختصاصی:** فایل CSS جدا (یا بلوک استایل) برای مودال پروفایل با استفاده از `--medical-*` و بدون گرادینت.
7. **گزینه «پروفایل من» در منو:** در صفحه اصلی (Layout عمومی)، لینک/دکمه «پروفایل من» می‌تواند مودال را باز کند تا کاربر بدون ترک صفحه، پروفایل را ببیند/ویرایش کند.

### پیشنهادی (اختیاری)

1. **کش محتوا:** در صورت تمایل به کاهش درخواست‌های مکرر، می‌توان محتوای مودال را برای مدت کوتاه (مثلاً تا بستن مودال) کش کرد و پس از «ذخیره» پروفایل، کش را باطل کرد.
2. **پیش‌بارگذاری:** در صورت ثابت بودن Layout صفحه اصلی، می‌توان پس از لود صفحه و در حالت idle یک بار `LoadProfileComponent` را صدا زد تا اولین باز شدن مودال سریع‌تر باشد.
3. **آمار استفاده:** در صورت نیاز، ثبت رویداد «باز شدن مودال پروفایل» برای آنالیز استفاده (با رعایت حریم خصوصی).
