# 🛡️ AI Guard Prompt - Pre-Response Checklist

> **این Prompt باید قبل از هر پاسخ AI اجرا شود**

---

## 🔍 Pre-Response Validation

قبل از تولید هر کد یا پیشنهاد، این سوالات را از خودت بپرس:

### ✅ 1. Information Check
- [ ] آیا تمام اطلاعات لازم را دارم؟
- [ ] آیا فایل‌های مرتبط را خوانده‌ام؟
- [ ] آیا الگوهای موجود در پروژه را بررسی کرده‌ام؟
- [ ] آیا هیچ حدس و فرضی نزده‌ام؟

**اگر جواب هر کدام "خیر" است → ❗ توقف + درخواست شفاف‌سازی**

---

### ✅ 2. Contract Compliance Check
- [ ] آیا قراردادهای مرتبط را خوانده‌ام؟
- [ ] آیا تغییر من با قراردادها سازگار است؟
- [ ] آیا هیچ قراردادی را نقض نمی‌کنم؟

**اگر جواب هر کدام "خیر" است → ❗ توقف + ارجاع به قرارداد**

---

### ✅ 3. Architecture Check
- [ ] آیا معماری لایه‌ای را رعایت می‌کنم؟
- [ ] آیا Business Logic در Service است؟
- [ ] آیا از ViewModel استفاده می‌کنم؟
- [ ] آیا از ServiceResult استفاده می‌کنم؟

**اگر جواب هر کدام "خیر" است → ❗ اصلاح + رعایت معماری**

---

### ✅ 4. Security Check
- [ ] آیا داده‌های حساس را Validate می‌کنم؟
- [ ] آیا CSRF Protection دارم؟
- [ ] آیا لاگ‌های حساس را Mask می‌کنم؟
- [ ] آیا Zero-Cache Policy را رعایت می‌کنم؟

**اگر جواب هر کدام "خیر" است → ❗ اضافه کردن امنیت**

---

### ✅ 5. Standards Check
- [ ] آیا از Persian DatePicker استفاده می‌کنم؟
- [ ] آیا از IImageUploadService استفاده می‌کنم؟
- [ ] آیا لاگ‌گذاری کامل دارم؟
- [ ] آیا مستندسازی کامل دارم؟

**اگر جواب هر کدام "خیر" است → ❗ رعایت استانداردها**

---

### ✅ 6. Impact Assessment
- [ ] آیا تغییر من Breaking Change ایجاد می‌کند؟
- [ ] آیا فایل‌های دیگر تحت تأثیر قرار می‌گیرند؟
- [ ] آیا تست ذهنی انجام داده‌ام؟
- [ ] آیا Edge Cases را در نظر گرفته‌ام؟

**اگر جواب هر کدام "خیر" است → ❗ تحلیل Impact**

---

### ✅ 7. Decision Authority Check
- [ ] آیا من تصمیم نهایی می‌گیرم؟
- [ ] آیا قرارداد را تغییر می‌دهم؟
- [ ] آیا معماری را تغییر می‌دهم؟

**اگر جواب هر کدام "بله" است → ❗ توقف + پیشنهاد + درخواست تأیید**

---

## 🚨 Hard Stop Conditions

اگر هر یک از موارد زیر رخ دهد، **باید متوقف شوی**:

1. ❗ عدم قطعیت در قرارداد
2. ❗ تعارض بین امنیت و درخواست
3. ❗ ابهام در داده‌های پزشکی
4. ❗ عدم دسترسی به فایل‌های کلیدی
5. ❗ تعارض بین قراردادها

**و باید اعلام کنی:**

> ❗ **توقف فوری - ادامه بدون شفاف‌سازی ممکن نیست**
